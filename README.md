# Cybersecurity Notes

A collection of practical notes, commands, and explanations gathered while studying cybersecurity and working through authorized labs.

These notes are written as quick references: the commands are ready to adapt, while the surrounding explanations clarify what each command does and when to use it.

## Contents

### Containers

- [Docker Enumeration](containers/docker-enumeration.md) — inspect containers, networks, processes, logs, mounts, environment variables, and image configuration.

### Tunneling and Pivoting

- [Ligolo-ng](tunneling/ligolo-ng.md) — create a TUN interface, connect an agent to the proxy, and route an internal subnet through the tunnel.
- [SSH Tunneling](tunneling/ssh-tunneling.md) — SSH access, key authentication, local and remote port forwarding, combined tunnels, and SCP transfers.

## Disclaimer

Use these notes only in systems and environments where you have explicit authorization. Commands that inspect containers, establish tunnels, or alter network routes can expose sensitive information or disrupt services when used carelessly.
